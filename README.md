# FAKE-NEWS-MISINFORMATION-DETECTION-SYSTEM
Machine learning web app that detects fake or real news using Kaggle Fake.csv and True.csv datasets. Includes text preprocessing, TF-IDF vectorization, and a trained classifier. Built with Python and Streamlit to allow users to input news text and get instant authenticity predictions.
#Dataset
This project uses the Fake and True News dataset
[Download dataset from kaggle](https://www.kaggle.com/datasets/razanaqvi14/real-and-fake-news?select=Fake.csv0
